# OASIS INFOBYTE — Web Development & Designing
## Level 1 · Task 1: Landing Page

**Project name:** Summit & Soul — Find Your Wild  
**Folder name required by the SIP PDF:** `WebDev-L1-LandingPage`  
**Tech stack:** HTML5 and CSS3 only; no JavaScript is required for this task.

## Objective
Create a visually polished static landing page for a fictional travel brand. This project is designed around the feature checklist in the OASIS INFOBYTE SIP Task List.

## Features checklist
- [x] Sticky navigation bar with 3 navigation links
- [x] Hero headline, subheadline, and call-to-action button
- [x] Multiple content sections: intro, journeys, travel philosophy, values, testimonial, contact
- [x] Footer with placeholder contact and social links
- [x] Consistent forest-green, cream, and warm-orange palette
- [x] Responsive layout using CSS Grid and Flexbox
- [x] `box-sizing: border-box` and responsive spacing to prevent overlap
- [x] Readable typography with separate heading and body fonts
- [x] Semantic HTML landmarks and focus-visible link styles

## Files
- `index.html` — page structure and content
- `styles.css` — colour palette, typography, responsive layout and styling
- `README.md` — project details and submission guidance

## How to run
1. Extract the project folder.
2. Open `index.html` in a modern browser; no build process or package installation is required.
3. For easier editing, open the folder in VS Code. You can use the Live Server extension if installed, but it is optional.

## Customisation
- Replace the fictional brand name and copy with your own if desired.
- Update the email address `hello@summitandsoul.example` before presenting it as a real contact. The `.example` domain is deliberately a placeholder.
- Replace social links with your own brand profiles if appropriate.
- Images are loaded from Unsplash image URLs and Google Fonts are loaded online, so those visual assets require an internet connection. If you need an offline version, download appropriately licensed assets and update the CSS URLs.
